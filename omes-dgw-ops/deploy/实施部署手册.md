# OMES设备软边缘网关 - 现场部署手册

面向**实施工程师**。只需使用研发交付的 **`omes-dgw-deploy`** 文件夹，无需 Java/Vue 源码或打包工具。

---

## 快速上手

按编号顺序执行根目录脚本（首次部署完整流程）：

| 步骤 | 脚本 | 何时执行 |
|------|------|----------|
| 1 | `01-初始化环境配置.bat` | 无 `.env` 时：从 `.env.example` 生成（实施包内可能已带 `.env`） |
| 2 | 编辑 `.env` | 每次部署前：改 `MOUNT_PATH`、`SQLITE_PATH`、中间件地址等 |
| 3 | `02-初始化InfluxDB.bat` | **仅外用 Influx** 且尚未建好 org/bucket/Token 时 |
| 4 | `03-启动.bat` | 导入镜像并启动全部容器 |
| 5 | `04-停止.bat` | 日常停止；改 `.env` 或重要配置后先停再启 |

```text
01-初始化环境配置.bat → 编辑 .env → [02-初始化InfluxDB.bat] → 03-启动.bat
                                                              ↓ 日常
                                                         04-停止.bat
```

**访问地址（默认）：**

- 前端：`http://服务器IP:12011`
- 后端 API：`http://服务器IP:12010`

## 一、部署包说明

将整个 `omes-dgw-deploy` 拷到服务器，例如 `D:\omes-dgw-deploy\`：

```text
D:\omes-dgw-deploy\
├── images\
│   ├── omes-dgw-server-1.0-SNAPSHOT.tar   ← 后端镜像
│   ├── omes-dgw-web-1.0.0.tar            ← 前端镜像
│   └── influxdb-2.7-alpine.tar               ← 自带 InfluxDB（USE_BUNDLED_INFLUX=true）
├── 01-初始化环境配置.bat
├── 02-初始化InfluxDB.bat
├── 03-启动.bat
├── 04-停止.bat
├── .env.example
├── InfluxDB说明.md
├── 实施部署手册.md                           ← 本文档
├── config-templates\                         ← 首次启动时复制到数据盘
├── scripts\                                  ← 由 03/04 自动调用，勿手改
└── docker-compose.yml                        ← 一般勿手改
```

| 内容 | 说明 |
|------|------|
| `images\*.tar` | 研发预构建镜像，`03-启动.bat` 自动 `docker load` |
| `.env` | 现场配置（实施包可能已含，否则由 `01` 生成，**必改**） |
| `MOUNT_PATH` | 数据根目录，日志/配置/中间件数据写在此，不在部署包内 |

**不包含：** 源代码、`docker/build` 打包工具。实时缓存与待写队列均在进程内（无需 Redis）。

## 二、前置条件

### 必须

1. **Windows 服务器**，已安装 Docker Desktop 或 Docker Engine（`docker version` 正常）
2. **SQLite 数据目录可写**（无需独立数据库进程）
   - `.env` 中 `SQLITE_PATH` 默认为容器内 `/app/data/omes-dgw.db`
   - 对应宿主机 `${MOUNT_PATH}/omes-dgw/data/omes-dgw.db`（compose 已挂载 `omes-dgw/data`）
   - **首次启动**后端时，应用内 **Flyway** 自动建业务表，**无需手工执行 DDL**
3. **`images\` 下三个 tar 齐全**（文件名勿改；自带 Influx 时无需现场 `docker pull`）

### InfluxDB（可选中间件）

| 情况 | 配置方式 |
|------|----------|
| 客户**已有** Influx | `.env` 保持 `USE_BUNDLED_INFLUX=false`，填写现网地址与 Token |
| 客户**没有** Influx | `.env` 设 `USE_BUNDLED_INFLUX=true`（见第四节场景 B） |

## 三、配置 `.env`

### 3.1 生成配置文件

1. 进入 `omes-dgw-deploy` 目录
2. 运行 `01-初始化环境配置.bat`（已存在 `.env` 则跳过，不覆盖）
3. 用记事本 / Notepad++ 编辑 `.env`

也可手动：`copy .env.example .env`

### 3.2 必改项

| 配置项 | 含义 | 示例 |
|--------|------|------|
| `MOUNT_PATH` | 数据根目录 | `D:/docker/collect` |
| `SQLITE_PATH` | SQLite 库文件（容器内路径） | `/app/data/omes-dgw.db` |
| `INFLUX_ADMIN_TOKEN` | Influx 2.x Token | 见 `02` 或客户管理员 |
| `INFLUX_ORG` / `INFLUX_BUCKET` | Influx 组织、桶 | 默认 `omes` / `collect_metrics` |

### 3.3 场景 A：外用 Influx（默认）

```properties
USE_BUNDLED_INFLUX=false
INFLUX_URL=http://host.docker.internal:8086
```

- `host.docker.internal`：从容器访问**安装 Docker 的本机**服务
- Influx 在**其他服务器**时：改 `INFLUX_URL` 为对应内网 IP
- Token 必须与现网一致

**Influx 首次接入**（客户未建好 org/bucket）：

1. 向客户索取 Influx **管理员 Token**
2. 运行 `02-初始化InfluxDB.bat`，按提示输入地址、Token、组织、桶名
3. 将生成的 `influx-app-credentials.env` 中 `INFLUX_*` 写入 `.env`

详见 `InfluxDB说明.md`。Influx 为时序库，无 SQL 建表。

### 3.4 场景 B：安装包自带 Influx

```properties
USE_BUNDLED_INFLUX=true
INFLUX_URL=http://influxdb:8086
```

确认 `INFLUX_ADMIN_TOKEN`、`INFLUX_ORG`、`INFLUX_BUCKET` 与 `.env` 中初始化项一致；**首次空库**由容器自动初始化。数据目录：`MOUNT_PATH\influxdb2\`。

**此场景无需运行 `02-初始化InfluxDB.bat`。**

### 3.5 端口与 CORS

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `FRONT_PUBLISH_PORT` | 12011 | 浏览器访问前端 |
| `APP_PUBLISH_PORT` | 12010 | 后端 API |
| `INFLUX_PUBLISH_PORT` | 8086 | 仅自带 Influx |

通过服务器 IP 访问前端时，`.env` 中 `CORS_ALLOWED_ORIGIN_PATTERNS` 需包含对应来源，例如：

```properties
CORS_ALLOWED_ORIGIN_PATTERNS=http://localhost:*,http://127.0.0.1:*,http://*:*
```

改端口后放行 Windows 防火墙。

## 四、启动与停止

### 首次启动

1. Docker 服务正常运行
2. `01-初始化环境配置.bat` → 编辑 `.env`
3. 外用 Influx 且需要时：`02-初始化InfluxDB.bat` → 更新 `.env`
4. `03-启动.bat`（自动 `docker load` + `docker compose up`，首次可能需数分钟）
5. 浏览器访问前端与 API

### 日常停止

运行 `04-停止.bat`。

### 配置变更后

| 改了什么 | 操作 |
|----------|------|
| `MOUNT_PATH` 下 `config-center.properties` | `04-停止.bat` → `03-启动.bat` |
| `.env` 中 SQLite / Influx 地址 | 同上，须先停再启 |

## 五、数据与日志

均在 **`MOUNT_PATH`** 下（如 `D:\docker\collect`），便于备份：

| 目录 | 内容 |
|------|------|
| `omes-dgw\logs` | 后端日志（含 `omes-dgw-server.log`） |
| `omes-dgw\config\config-center.properties` | 后端业务配置 |
| `omes-dgw\monitoring` | 监控告警规则 |
| `omes-dgw\data` | SQLite 与运行时数据（如 Influx 降级文件） |
| `nginx\logs` | 前端 Nginx 日志 |
| `influxdb2` | 仅自带 Influx |

重装前先 `04-停止.bat`，勿删运行中数据目录。

## 六、常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 缺少 tar | 镜像包未拷贝全 | 向研发索取完整 `omes-dgw-deploy` |
| `MOUNT_PATH must be set` | 未配置数据目录 | 编辑 `.env` 设置 `MOUNT_PATH` |
| `dependency omes-dgw-server failed to start` | 后端启动失败或未 healthy（`omes-dgw-web` 在等后端） | 执行 `docker compose logs omes-dgw-server` 查根因 |
| 日志 `unable to open database file` / SQLite 权限错误 | 数据目录不可写 | 确认 `MOUNT_PATH/omes-dgw/data` 存在且可写；`SQLITE_PATH` 指向该挂载点 |
| 后端健康检查失败 | SQLite/Influx 异常 | 核对 `SQLITE_PATH`、Influx；查看 `omes-dgw/logs` |
| Influx 报错 | Token/Org/Bucket 不一致 | 核对 `INFLUX_*`；外用时重跑 `02` |
| 页面打不开 | 端口占用 / 防火墙 | 改 `FRONT_PUBLISH_PORT` 并放行 |
| 页面能开但接口 405/异常 | Nginx 未代理 `/api` 或后端未就绪 | 重新 `03-启动.bat`（会同步 `nginx/default.conf`）；确认 `omes-dgw-server` 健康 |
| 改配置不生效 | 未重启 | `04-停止.bat` 后 `03-启动.bat` |

**可选排查命令：**

```bat
cd /d D:\omes-dgw-deploy
docker compose ps
docker compose logs -f omes-dgw-server
```

## 七、交付前检查清单

- [ ] Docker 正常（`docker version`）
- [ ] `images\` 三个 tar 齐全
- [ ] `MOUNT_PATH/omes-dgw/data` 可写，`.env` 中 `SQLITE_PATH` 正确
- [ ] Influx 模式（自带 / 外用）与 `.env` 一致
- [ ] 外用 Influx 时 Token/Org/Bucket 已核对或已执行 `02`
- [ ] `03-启动.bat` 成功，`docker compose ps` 中 `omes-dgw-server`、`omes-dgw-web` 为 running
- [ ] 浏览器可访问前端，核心功能验收通过
- [ ] `04-停止.bat` 可正常停止

## 附录：脚本与文件对照

| 文件 | 实施是否操作 | 说明 |
|------|----------------|------|
| `01-初始化环境配置.bat` | 首次 | 生成 `.env` |
| `02-初始化InfluxDB.bat` | 按需 | 外用 Influx 建 org/bucket/Token |
| `02-初始化InfluxDB.ps1` | 否 | `02` 的内部逻辑 |
| `03-启动.bat` | 常用 | 加载镜像、复制配置模板、启动 compose |
| `04-停止.bat` | 常用 | 停止 compose（含 profile 中间件） |
| `scripts\03-*.ps1` / `04-*.ps1` | 否 | 由 03/04 调用 |
| `init-influx.env.example` | 可选 | `02` 的默认参数模板 |
| `influx-app-credentials.env` | 否 | `02` 运行后生成，内容写入 `.env` |
| `InfluxDB说明.md` | 阅读 | Influx 初始化补充说明 |

| 步骤 | 执行方 | 说明 |
|------|--------|------|
| 研发 `docker build` + `docker save` | 研发 | 产出应用镜像 tar；`build-middleware` 拉取并保存 Influx |
| 现场 `docker load` | `03-启动.bat` | 加载三个 tar；本地已有同名镜像则跳过 |
| 现场 `docker compose up` | `03-启动.bat` | 创建并运行业务容器 |

如有疑问，请联系项目组研发，并说明是 **omes-dgw-deploy 现场部署** 问题。
